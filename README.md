## 달력 보기

`index.html`과 `plan.js`를 같은 폴더에 두고 `index.html`을 브라우저로 열기 → 시작일 선택.

## 일정 수정

재료 순서·양은 `plan.js`의 `BLOCKS`, `phase()`에서 수정 → `node build-md.js`로 `03_이유식달력.md` 다시 생성.

> 국내에서 흔히 쓰는 일반 기준. 아기마다 다를 수 있으며 알레르기·질환 이력이 있으면 소아청소년과와 먼저 상의.
